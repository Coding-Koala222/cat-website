# A website all about cats!
This is an example website for the Hack Club Boba Drops program. 

## The requirements of the Boba Drops program include:

### No AI use.
Website code must be hand-written.

### HTML & CSS only.
No JavaScript or other languages, this program is for beginners mastering the basics. There are other Hack Club programs for JS!

### At least 5 HTML & CSS features.
With at least one being CSS and at least one being an image.

### Good effort & accessible.
No tiny fonts, excessive color clashes, or illegible text. It doesn't have to be beautiful, it just has to be readable and genuine.
